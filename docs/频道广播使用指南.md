# 频道广播使用指南

## 概述

Bot 支持向指定的 Telegram 频道或群组发送广播消息，包括文字消息和图文消息。

## 频道ID vs 群组名称

### 重要区别

- **频道ID** ≠ **群组名称**
- **频道ID** 是 Telegram 分配给每个聊天的唯一标识符
- **群组名称** 只是显示名称，不能直接用于 API 调用

### 频道ID的格式

1. **公开频道/群组**：`@username`
   - 例如：`@mychannel`
   - 这是频道的公开用户名

2. **私有频道/群组**：数字ID
   - 例如：`-1001234567890`
   - 通常是负数，以 `-100` 开头

## 如何获取频道ID

### 方法一：使用 Bot 命令（推荐）

1. **将 Bot 添加到频道/群组**
   - 进入目标频道或群组
   - 添加 Bot 为成员
   - 如果是频道，需要将 Bot 设为管理员

2. **在频道/群组中发送命令**
   ```
   /get_chat_id
   ```
   或使用别名：
   ```
   /chatid
   ```

3. **Bot 会返回聊天信息**
   ```
   📋 聊天信息

   🏷️ 名称：我的频道
   📍 类型：📢 频道
   🆔 Chat ID：-1001234567890

   💡 使用此ID发送频道广播：
   /broadcast_channel -1001234567890

   ⚠️ 注意：Bot必须是频道管理员
   ```

4. **复制 Chat ID 使用**
   - 点击 ID 可以复制
   - 在广播命令中使用这个 ID

### 方法二：通过第三方 Bot

使用 Telegram 官方的 [@userinfobot](https://t.me/userinfobot) 或 [@getidsbot](https://t.me/getidsbot)：

1. 将这些 Bot 添加到频道/群组
2. 转发一条频道消息给这些 Bot
3. Bot 会显示频道ID

### 方法三：通过网页版 Telegram

1. 打开 [Telegram Web](https://web.telegram.org)
2. 进入目标频道
3. 查看浏览器地址栏
4. URL 中会包含频道ID，例如：
   ```
   https://web.telegram.org/z/#-1001234567890
   ```

## 使用频道广播功能

### 前置条件

✅ Bot 必须是频道/群组的成员  
✅ Bot 必须是频道管理员（频道必须）  
✅ Bot 需要有发送消息权限  
✅ 你必须是 Bot 的管理员

### 发送文字消息

```
/broadcast_channel @mychannel
```
或
```
/broadcast_channel -1001234567890
```

然后：
1. Bot 验证频道并显示频道信息
2. 发送要广播的文字内容
3. Bot 显示预览
4. 回复 `确认` 发送，或 `取消` 取消

### 发送图文消息

```
/broadcast_channel @mychannel
```

然后：
1. Bot 验证频道
2. 发送图片（可以添加说明文字）
3. Bot 显示预览
4. 回复 `确认` 发送

### 使用别名

为了快速操作，可以使用简短别名：

```
/gbc @mychannel
```

## 常见问题

### Q1: 为什么提示"无法访问频道"？

**可能原因：**
- Bot 未被添加到频道
- 频道ID错误
- Bot 没有足够的权限

**解决方法：**
1. 确认 Bot 已添加到频道
2. 使用 `/get_chat_id` 获取正确的 ID
3. 确保 Bot 是频道管理员

### Q2: 为什么提示"Bot在频道中没有管理员权限"？

**解决方法：**
1. 进入频道设置
2. 点击"管理员"
3. 添加 Bot 为管理员
4. 授予"发送消息"权限

### Q3: 群组和频道有什么区别？

- **群组**：成员可以互相聊天
  - 普通群组：最多 200,000 人
  - 超级群组：最多 200,000 人
  
- **频道**：单向广播
  - 只有管理员可以发消息
  - 成员数量无限制

**两者都可以使用 `/broadcast_channel` 命令**

### Q4: 可以同时向多个频道发送吗？

目前不支持。如需向多个频道发送，需要分别执行命令。

### Q5: 公开频道的用户名在哪里找？

1. 进入频道
2. 点击频道名称查看信息
3. 如果是公开频道，会显示链接：`t.me/channelname`
4. `channelname` 就是用户名，使用时加 `@`：`@channelname`

## 命令速查表

| 命令 | 别名 | 说明 |
|------|------|------|
| `/broadcast_channel <ID>` | `/gbc` | 向指定频道发送广播 |
| `/get_chat_id` | `/chatid` | 获取当前聊天的ID |
| `/cancel` | - | 取消当前广播操作 |

## 权限要求

### Bot 权限
- ✅ 必须是频道成员
- ✅ 必须是频道管理员（频道）
- ✅ 必须有发送消息权限

### 用户权限
- ✅ 必须是 Bot 配置的管理员
- ✅ 在配置文件中设置 `ADMIN_USER_IDS`

## 安全提示

⚠️ **重要**：
- 频道广播功能仅限管理员使用
- 发送前会显示预览，需要确认
- 建议先在测试频道测试
- 注意消息内容，避免误发

## 技术支持

如遇问题，请检查：
1. Bot 日志文件
2. 频道权限设置
3. Bot 配置文件中的管理员ID
