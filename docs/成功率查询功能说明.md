# 成功率查询功能说明

## 功能概述

新增了3个命令用于查询商户在不同时间范围内的订单成功率：

- `/cgl_15m` - 查询最近15分钟的成功率
- `/cgl_1h` - 查询最近1小时的成功率
- `/cgl_day` - 查询当天的成功率

## 使用方法

### 1. 查询最近15分钟成功率

```
/cgl_15m
```

### 2. 查询最近1小时成功率

```
/cgl_1h
```

### 3. 查询当天成功率

```
/cgl_day
```

## 返回信息

查询成功后，机器人会显示以下信息：

- 🏪 商户ID
- ⏰ 时间范围
- 📈 总订单数
- ✅ 成功订单数
- 💯 成功率（百分比）

## 后端接口

### 接口地址

```
POST /telegram/merchant_success_rate
```

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| merchant_id | string | 是 | 商户ID |
| time_range | string | 是 | 时间范围：15m（15分钟）、1h（1小时）、d（当天） |

### 响应格式

```json
{
    "code": 200,
    "msg": "success",
    "merchant_id": "202409111",
    "time_range": "15m",
    "total_count": 100,
    "success_count": 95,
    "success_rate": "95.00"
}
```

## 技术实现

### 1. API 客户端方法

在 `app/utils/api_client.py` 中新增了 `query_merchant_success_rate` 方法：

```python
async def query_merchant_success_rate(self, merchant_id: str, time_range: str) -> Dict[str, Any]:
    """
    查询商户成功率
    
    参数:
        merchant_id: 商户号
        time_range: 时间范围 (15m, 1h, d)
    
    返回:
        成功率数据字典
    """
    return await self._post("telegram/merchant_success_rate", {
        "merchant_id": merchant_id,
        "time_range": time_range
    })
```

### 2. 命令处理器

在 `app/bot/commands.py` 中新增了3个命令处理函数：

- `cgl_15m_command()` - 处理 /cgl_15m 命令
- `cgl_1h_command()` - 处理 /cgl_1h 命令
- `cgl_day_command()` - 处理 /cgl_day 命令

以及一个通用的查询函数：

- `query_success_rate()` - 执行实际的查询逻辑

### 3. 命令注册

在 `app/main.py` 中注册了这3个命令处理器。

## 错误处理

系统会处理以下错误情况：

1. **未绑定商户** - 提示用户先绑定商户账号
2. **后端服务不可用** - 显示连接错误信息
3. **请求超时** - 提示用户稍后重试
4. **其他错误** - 显示具体错误信息

## 多语言支持

该功能支持中英文双语：

- 中文用户看到中文界面
- 英文用户看到英文界面

语言根据用户的语言设置自动切换。

## 注意事项

1. 用户必须先绑定商户账号才能使用此功能
2. 查询结果基于后端系统的实时数据
3. 成功率计算包含所有类型的订单（代收和代付）
4. 时间范围的计算基于服务器时间
