# 数据库迁移说明 - 添加 enable_ocr 字段

## 迁移内容

为 `merchants` 表添加 `enable_ocr` 字段，用于存储每个会话的OCR开关状态。

## 执行迁移

### 方法1：使用 Alembic（推荐）

```bash
# 执行迁移
alembic upgrade head

# 如果需要回滚
alembic downgrade -1
```

### 方法2：手动执行 SQL

如果不使用 Alembic，可以手动执行以下 SQL：

#### SQLite
```sql
ALTER TABLE merchants ADD COLUMN enable_ocr BOOLEAN NOT NULL DEFAULT 1;
```

#### PostgreSQL
```sql
ALTER TABLE merchants ADD COLUMN enable_ocr BOOLEAN NOT NULL DEFAULT TRUE;
COMMENT ON COLUMN merchants.enable_ocr IS '是否启用OCR图片识别';
```

#### MySQL
```sql
ALTER TABLE merchants ADD COLUMN enable_ocr TINYINT(1) NOT NULL DEFAULT 1 COMMENT '是否启用OCR图片识别';
```

## 字段说明

| 字段名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_ocr` | Boolean | `True` | 是否启用OCR图片识别功能 |

## 影响范围

- **新绑定的会话**：默认开启 OCR（`enable_ocr = True`）
- **已存在的会话**：迁移后默认开启 OCR（`DEFAULT 1`）
- **不影响现有功能**：只是增加了控制开关

## 验证迁移

迁移完成后，可以通过以下方式验证：

### 1. 检查数据库结构
```sql
-- SQLite
PRAGMA table_info(merchants);

-- PostgreSQL
\d merchants

-- MySQL
DESCRIBE merchants;
```

### 2. 测试功能
```bash
# 在 Telegram 中执行
/toggle_ocr          # 查看当前状态
/toggle_ocr off      # 关闭OCR
/toggle_ocr on       # 开启OCR
```

## 回滚方案

如果需要回滚此迁移：

### 使用 Alembic
```bash
alembic downgrade -1
```

### 手动执行 SQL
```sql
ALTER TABLE merchants DROP COLUMN enable_ocr;
```

## 注意事项

⚠️ **备份数据库**
- 执行迁移前建议备份数据库
- 特别是生产环境

⚠️ **停机时间**
- 此迁移通常很快，但建议在低峰期执行
- 对于大表可能需要几秒钟

⚠️ **兼容性**
- 迁移脚本兼容 SQLite、PostgreSQL、MySQL
- 已有数据不会丢失
- 默认值确保功能正常
