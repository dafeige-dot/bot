========================================
🌍 多语言功能使用说明
========================================

✨ 您的 Bot 现在支持中英文双语！

========================================
📋 更新步骤
========================================

1. 更新数据库（可选，如果有旧数据）
   
   Windows:
   双击运行: update_language_format.bat
   
   或者在命令行:
   python update_language_format.py


2. 重启 Bot
   
   Windows:
   双击运行: start.bat
   
   或者在命令行:
   python run.py


========================================
🎯 如何切换语言
========================================

在 Telegram 中与您的 Bot 对话：

1. 发送命令:
   /language

2. 点击按钮选择语言:
   🇨🇳 中文
   🇺🇸 English

3. 完成！您的选择会自动保存

========================================
📱 用户体验
========================================

✅ 首次使用（未注册）
   - 会显示中英文双语欢迎信息
   - 注册后可使用 /language 切换

✅ 注册后
   - 所有消息根据您选择的语言显示
   - 可随时切换语言

========================================
🔧 所有命令都支持双语
========================================

/start      - 开始使用 / Start
/language   - 切换语言 / Change Language
/help       - 帮助 / Help
/myid       - 我的ID / My ID
/balance    - 余额 / Balance
/orders     - 订单 / Orders
/history    - 历史 / History
/upload     - 上传图片 / Upload
/reset      - 重置 / Reset
/cancel     - 取消 / Cancel

========================================
💡 使用示例
========================================

例1: 切换到英文
-----------------
您: /language
Bot: 🌍 语言设置
     请选择您的语言：
     [🇨🇳 中文]  [🇺🇸 English]

您: [点击 English]
Bot: ✅ Language changed to English

您: /start
Bot: 👋 Welcome back, John!
     🏪 Merchant Name: ...
     💰 Current Balance: $0.00


例2: 切换回中文
-----------------
您: /language
Bot: 🌍 Language Settings
     Please select your language:
     [🇨🇳 Chinese]  [🇺🇸 English]

您: [点击 中文]
Bot: ✅ 语言已切换为中文

您: /start
Bot: 👋 欢迎回来，张三！
     🏪 商户名称：...
     💰 当前余额：¥0.00
